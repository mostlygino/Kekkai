# Code of conduct

Kekkai is a small project and wants to stay a pleasant one to work on.

- Be kind and assume good intent. Critique code and ideas, never people.
- No harassment, insults, discriminatory language or unwelcome attention, in any space connected to the
  project: issues, pull requests, discussions and anywhere you represent it.
- Respect people's time and privacy. Don't share anyone's private information without their permission.

If someone's behaviour worries you, contact the maintainer privately through the
[security contact](SECURITY.md#reporting) or a private message to [@mostlygino](https://github.com/mostlygino).
Reports are handled in confidence. The maintainer may remove comments, close threads or block people who
don't follow this code.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org).
